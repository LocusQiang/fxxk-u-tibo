[English README](../README.md) · [中文说明](../README.zh-CN.md)

Original wording / 原文：

> fxxk u tibo，no more Selected model is at capacity. Please try a different model.

The project name **fxxk u tibo** stays the same in every version. The rest adapts the slogan and the error message into each language. These are slogan translations, not additional application UI languages. Wording improvements from speakers of each language are welcome.
